# BrownDust2 MOD 管理器

一个使用 Python 标准库编写的桌面工具，帮助玩家自动定位《棕色尘埃2》的 BrownDustX MOD 目录。

## 功能

- 深色高级管理界面，包含总览、MOD 列表、路径查找和设置导航。
- 自动扫描本机可访问的磁盘，查找目标目录。
- 支持手动选择目录，以及通过系统文件管理器打开目录。
- 展示目录内的文件名、类型、大小和路径。
- 支持按文件名、类型或路径过滤列表。
- 统计文件、子目录和条目总数。
- 遇到无权限目录时跳过，不因单个目录读取失败而中断。

目标目录结构：

```text
Neowiz\Browndust2\BrownDust2\_10000002\BepInEx\plugins\BrownDustX\mods
```

## 运行方式

需要 Python 3.10 或更新版本，无需安装第三方依赖。

```bash
python BrownDust2_MOD_Manager_Advanced.py
```

## 使用说明

1. 启动程序。
2. 点击“自动查找”扫描可访问的磁盘；磁盘较大时可能需要几分钟。
3. 如果未自动找到，点击“选择目录”手动指定 `BrownDustX\mods`。
4. 在文件列表中查看内容，使用右上角过滤框快速筛选。
5. 点击“打开文件夹”在系统文件管理器中查看目录。

## 当前限制

- 当前版本仅查找和查看文件，不会修改、删除或移动 MOD 文件。
- MOD 启用/禁用、备份恢复、配置持久化计划在后续版本实现。
- 全盘搜索速度取决于磁盘大小、权限和文件系统状态。

## 开发与安全

该项目不会主动连接游戏服务器，也不需要账号或密码。使用前建议自行备份游戏 MOD 文件。
